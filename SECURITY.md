# Security

Fairtoll sits in a site's request path and handles payments, so a flaw in it can give away pages that should be paid for, charge a bot wrongly, or break the site it protects.

## Reporting a vulnerability

Report it privately through GitHub: open the [Security tab](https://github.com/mechrabbit/fairtoll/security) and choose **Report a vulnerability**. Don't open a public issue, pull request or discussion for it.

Include what you did, what happened, and what you expected, with the config you used. A request that gets past a block or a charge, a payment accepted when it shouldn't be, or a way to make Fairtoll fail closed and take a site down are all in scope.

Once a fix is released, the advisory is published, and you're credited unless you'd rather not be.

## Supported versions

Only the latest release gets security fixes.
