# Code of conduct

Fairtoll follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), in its issues, pull requests, discussions and any other space the project runs.

To report behaviour that breaks it, email [hello@fairtoll.net](mailto:hello@fairtoll.net). Reports are read only by the maintainer and kept confidential.
